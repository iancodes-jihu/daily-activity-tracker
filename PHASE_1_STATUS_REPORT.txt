KNOWN LIMITATIONS (By Design)
=============================

1. Requires Baseline Data
   - Needs 3+ days of activity to detect deviations
   - First 3 days will have no baseline
   - (Intentional: avoids false alarms on new data)

2. Z-Score Threshold Fixed
   - Currently 2.0 (95% confidence)
   - Code change required to adjust
   - (Phase 2: Add configuration UI)

3. Static App Categorization
   - Categories hardcoded in main.py
   - No machine learning classification
   - (Phase 3: Could add ML-based categorization)

4. Daily-Only Analysis
   - No intra-day patterns detected
   - Can't distinguish morning vs afternoon
   - (Phase 2: Could add hourly analysis)

5. No Trend Analysis
   - Only detects single-day deviations
   - Can't predict week-long patterns
   - (Phase 3: Could add trend forecasting)

All limitations are documented and intentional for Phase 1 scope.
