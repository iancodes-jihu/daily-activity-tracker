## General Information

A simple web-based system for logging daily activities.
The system supports basic input, persistent storage using a database, and summary display through a web interface.

This project focuses on building a **complete end-to-end system** from user input to data storage and presentation.

## Features

* Input daily activities through a web form
* Store activity data persistently in a database
* Display a summary of logged activities
* Simple and minimal UI
* Modular backend structure

<a name="technologies-used"></a>

## Technologies Used

* Python 3.x
* Flask
* SQLite
* HTML (Jinja Template)

<a name="setup"></a>

## Setup

1. Install Python on your device
2. Clone this repository
3. Create and activate a virtual environment
4. Install dependencies from `requirements.txt`

<a name="usage"></a>

## Usage

1. Navigate to the project directory
2. Activate the virtual environment
3. Run the Flask application
4. Open the application in a browser
5. Input and view daily activities through the web interface
